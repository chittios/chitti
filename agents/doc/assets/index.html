Chitti OS

An agentic operating system, built from scratch, where the agent is the driver.

Read the docsSource

There is no exec(binary) → trap into syscalls. Instead a tiny language model runs on the CPU, on bare metal, and every effect it wants flows through a capability-checked, audited, grammar-constrained ABI. Model output is an untrusted plan — it never causes a side effect directly.

What makes it different

Agents as apps

Installed from a signed public registry, "programmed" in markdown — a SOUL, skills, and a manifest of permissions.

Capability ABI

Every tool call is capability-checked, scope-checked, taint-gated, and written to an append-only audit log.

Agents that talk

Byte-stream and datagram channels between agents — the Linux-pipe/socket analog, as unforgeable capabilities.

Service agents

Long-running native daemons: this very page is served by the Doc agent over the native HTTP service agent.
